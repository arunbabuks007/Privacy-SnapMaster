1. Overview & Summary

✅ Short Version

SnapMaster captures screenshots and lets you annotate them entirely on your device. We do not collect, transmit, or share any personal data, screenshots, or usage information with anyone — ever. Everything stays locally in your browser.

SnapMaster ("the Extension", "we", "our") is a Chrome browser extension that allows users to capture visible-area screenshots, full-page scroll screenshots, and selected-area screenshots, then edit them with annotation tools (pen, arrows, text, blur, crop, etc.). The Extension is designed to operate entirely offline and locally within the user's browser.

This Privacy Policy explains what information the Extension accesses, how it is used, and the rights you have regarding that information.

2. What Data We Collect

📵 We Do NOT Collect

We do not collect, store remotely, or transmit: personal identifiers, browsing history, page content, form data, cookies, passwords, financial information, health information, location data, user communications, or any other personal or sensitive data.

The only data the Extension ever handles is:

  • Screenshot image data — pixel data of the visible browser tab, captured only when you explicitly trigger a capture action. This data is stored locally in your browser via chrome.storage.local and is never transmitted anywhere.
  • Editor preferences — tool settings such as brush size, colour, font size, etc., stored locally in session memory only. These are not persisted beyond the editor session.
⚠️ Important Note on Screenshot Content

When you capture a screenshot, the image may contain sensitive information visible on your screen at the time of capture (e.g., banking pages, personal emails). This image data is stored only on your local device and is never transmitted to us or any third party. You are solely responsible for managing your captured screenshots.

3. Extension Permissions Explained

SnapMaster requests the following Chrome permissions. Each permission is used exclusively for core screenshot functionality and is not used to collect user data:

Permission Why It Is Required Data Sent Externally?
activeTab Capture a screenshot of the currently active browser tab when you click the extension icon or use a keyboard shortcut. Access is granted only for the duration of the capture action. None
storage Save captured screenshots to chrome.storage.local (local device only) so the editor page can access the image after it opens. Data never leaves the device. Local only
scripting Inject the selection-area overlay and scroll-capture scripts into the active tab when you choose "Select Area" or "Full Page Scroll" capture modes. Scripts run locally and do not transmit page content. None
host_permissions (<all_urls>) Required by scripting to inject content scripts into any tab regardless of domain, so you can capture screenshots on all websites. No page content is read or transmitted — the script only controls the screenshot overlay UI. None

4. How Data Is Stored

All data handled by SnapMaster is stored exclusively using the browser's built-in local storage API (chrome.storage.local), which keeps data on your device only. This storage:

  • Is never synced to Google accounts or any remote server (we explicitly do not use chrome.storage.sync).
  • Is never accessible by us, Google, or any third party.
  • Can be cleared at any time by removing the extension or clearing browser data.
  • Is limited to a small history of recent screenshots (up to 50 images) stored as data URLs in your browser's local storage.
🌐 No External Network Requests

SnapMaster makes zero network requests. It does not connect to any server, API, analytics service, cloud storage, or third-party service. You can verify this by inspecting the extension's network activity in Chrome DevTools.

5. Data Sharing & Third Parties

We do not share, sell, rent, trade, or otherwise transfer any data to third parties. Specifically:

  • No analytics or telemetry services are embedded in the Extension.
  • No advertising networks or data brokers receive any information.
  • No crash reporting services receive data about your usage.
  • No cloud services receive your screenshots or any other data.

The Extension does not integrate with any third-party SDKs, libraries loaded from external CDNs, or remote scripts of any kind. All code runs locally from the installed extension package.

6. Data Retention & Deletion

Because all data is stored locally on your device, you have full control over it:

  • Automatic cleanup: The extension retains a maximum of 50 screenshots in local storage. Older entries are automatically removed when the limit is reached.
  • Manual deletion: You can delete all extension data at any time by going to chrome://settings/content/all, finding the extension, and clearing its storage.
  • Uninstall: Removing the extension from Chrome automatically deletes all locally stored data, including screenshots.

We have no ability to delete data on your behalf because we never receive or hold any data from you.

7. Children's Privacy

SnapMaster does not knowingly collect any personal information from children under the age of 13 (or the applicable age of digital consent in your jurisdiction). Because the Extension collects no personal data whatsoever, it is inherently safe for all age groups. If you are a parent or guardian and have concerns, please contact us.
